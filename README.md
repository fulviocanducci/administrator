# Nexo Admin

Dashboard administrativo responsivo feito com HTML, CSS, Bootstrap, Bootstrap Icons e jQuery.

## Executar

Abra `index.html` no navegador. As fontes e bibliotecas usam CDN, então precisam de conexão com a internet.

## Stack

- Bootstrap 5.3.8 (versão estável; Bootstrap 6 ainda está em alpha)
- Bootstrap Icons 1.13.1
- jQuery 3.7.1
- HTML5, CSS3 e JavaScript

O formulário de cadastro adiciona linhas de demonstração à tabela atual. Cadastros, relatórios e demais dados ainda não estão conectados a um backend.
